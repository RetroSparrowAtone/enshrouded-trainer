# Security Policy

## Scope
This repository is a cheat/trainer for the single-player and co-op
Enshrouded game. It is intended for **offline / private co-op use only**.

- Do **not** use this on public servers or in any context that violates
  Keen Games' EULA.
- Do **not** publish memory offsets harvested from anti-cheat-protected
  builds.

## Reporting
Open a private security advisory. Do not file a public issue for:
- privilege escalation in the injector
- arbitrary code execution via plugin loader
- signature bypass / spoofer details

## Supported versions
| Trainer | Game build | Status |
|---------|-----------|--------|
| 2.4.x   | 0.7.2.1   | supported |
| 2.3.x   | 0.7.1.x   | EOL |

Use at your own risk. The authors are not responsible for bans, save
corruption, or data loss.
